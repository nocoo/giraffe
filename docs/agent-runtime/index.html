    Startup & persistencemanual invocation ≠ automatic service

    01 / Authorize once

    bun run agent login

    Browser consent + PKCE. Scoped API credentials and model configuration stay in ~/.config/giraffe/. This page reads neither.

    02 / Start an occurrence

    bun run agent work --no-push

    work is one-shot, not an installed service. SQLite restores conversations; an account lock prevents a second local owner. No implicit replay of interrupted mutations.

    03 / Other commands ≠ work

    watch serves observation/report jobs while running. repair is the separate opt-in dependency cron with dedicated clones/branches and exact-code Astra review. Its grants do not describe this main-workspace flow.
